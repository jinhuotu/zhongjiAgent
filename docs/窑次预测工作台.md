# 窑次预测工作台

当前流程：预览并确认上传数据 → 四模型比较 → 用户手动选型 → 计算试算 / AI 生成看板 → 调整计划并比较 → 点击提醒查看依据。

## 操作

1. 在“能耗 / 窑次预测”选择 xls、xlsx 或 zip，先确认识别到的窑号、窑次和字段，再导入。
2. 标准“温度 / 压力”双表自动合并。其他单表支持自动识别常用字段，或手动调整列映射。自定义映射需要时间列及至少一个工况字段；字段数值沿用页面标明的单位，请上传前完成单位换算。
3. 必要时补充曲线版本、装载量，保存匹配信息。装载量只影响相似窑次筛选，当前算法没有装载变化的热负荷响应模型。
4. 比较四个模型的曲线、整窑用气、回放 MAE 和适用条件，点击“使用此模型”。数据不足的模型不可选择。修改匹配信息后需重新选型。
5. 拖动当前回放时刻，填写未来计划参数和可选分析侧重点。点击“仅重新试算”查看计算结果，或“生成 AI 看板与报告”调用模型管理中启用的对话模型。
6. 看板展示所选模型的预测、六温区工况、窗口耗气、参数变化和 AI 结论。AI 决定允许的图表组件、排序及分析内容，指标和曲线由计算服务绑定。
7. 点击提醒进入温控曲线详情，查看窑次、温区、时间段和判断依据。点击工况图中的温区可查看当前实测值。
8. AI 生成成功后自动保存独立快照，包含当时的数据、模型、参数、分析和看板。历史记录按用户隔离，回看不会重新计算。可下载 Markdown 报告。

## 当前支持的试算参数

- 未来设定温度偏移：-100～100 ℃，当前时刻后平滑过渡，15 分钟后达到目标偏移。相似窑次基线不支持该参数。
- 剩余计划时长比例：0.5～1.5，1 为原计划，对剩余计划进行时间伸缩。相似窑次基线按相同进度对齐，其他模型重新计算温度变化速率和耗气。
- 以上为软件试算边界，不是设备工艺安全限值；调整后的设定温度限定为 0～1800 ℃。仍需现场确认工艺可行性和产品质量。
- 参数只影响当前时刻之后的试算，原始上传工况不覆盖。改变输入会清除页面上已失效的结果，需重新计算或生成。

## 预测与验证范围

复用当前四种简化气耗算法：相似窑次基线、温度和升温速率的线性数据模型、两参数机理模型、分阶段残差融合模型。训练数据排除当前窑次、重叠窑次和之后的窑次。

当前为上传数据回放与未来设定计划试算。燃气模型预测流量及其积分耗量，温度模型预测六区平均温度。温度预测使用当前实测温度向未来设定曲线的一阶响应模型，阶段响应速度不同，区间随预测时长扩大。温控图的红线为实时温度，蓝线为预测温度，黄色虚线为设定计划，预测区间用细虚线表示。15/30/60 分钟展示预测窗口的耗气及实际覆盖时长，尚不代表完成了在线滚动独立精度验证。模型估计差值不能当作已实现节能。

AI 未配置、余额不足或返回格式错误时，页面保留数值试算预览并展示错误，不保存为 AI 成功结果。生成时使用系统现有模型管理配置。

## 接口与部署

- POST /api/v1/kiln-cycles/preview：只预览，不写入数据库。
- POST /api/v1/kiln-cycles/upload：确认导入；可选 mappingsJson 指定文件的列映射。
- GET /api/v1/kiln-cycles/{id}：识别覆盖情况和四模型对比。
- POST /api/v1/kiln-cycles/{id}/analyze：按 selectedModel、cursorHour、parameters 计算。
- POST /api/v1/kiln-cycles/{id}/report：计算后调用 AI，成功后保存快照。
- GET /api/v1/kiln-cycles/{id}/runs、/runs/{runId}：当前用户的历史快照。

新增数据库迁移 0031_kiln_analysis_runs，部署前运行 python -m alembic upgrade head。Windows 开发 API 未启用热重载，修改后需重启。
