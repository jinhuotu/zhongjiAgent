# 窑炉算法库新增算法

1. 在 `packages/common/kiln_studio_engine.py` 的 `_ALGORITHM_DEFINITIONS` 增加一条元数据。使用稳定且唯一的 `key`，填写定位、优点、使用好处、场景、局限、数据要求和版本。可按实际计算结构填写 `inferenceComplexity`，在没有实测耗时的实验中用于定性比较。试验中的算法用 `experimental`，正式上架用 `enabled`，下架用 `disabled`。
2. 在同文件的 `_IMPLEMENTATIONS` 登记预测函数和训练函数。训练函数接收预处理后的训练集、当前配置和机理参数，返回可序列化的产物。有特定输入要求时登记可用性检查函数，并返回用户能理解的原因。预测函数从保存产物和预测起点特征计算单个预测值。
3. 用同一数据、机理和窗口运行算法对比。检查验证集及测试集覆盖率，然后点击卡片，保存模型版本并重新回放。新增算法会自动进入卡片、回测曲线及可用时的 AI 候选范围。

Lasso 示例在 `fit_lasso()` 中使用训练集标准化输入和 L1 惩罚，输出与岭回归相同形状的截距和权重，复用线性预测实现。它可以解释哪些测点参与预测，权重反映历史关联。算法版本固定了默认惩罚规则。

下架后保留预测实现和稳定算法键，已保存模型仍可推理。调整模型产物的含义或结构时，提升算法版本，并按保存产物的 `algorithmVersion` 保留旧版读取路径。旧的五种算法产物可视为版本 `1`。
